# Vanguard CRM

CRM команды Vanguard: подготовка к TOEFL iBT, Duolingo, IELTS (Астана, Алматы, Шымкент).

- `index.html` — весь сайт (одна страница), работает на GitHub Pages.
- `supabase-setup.sql` — создание базы данных в Supabase (SQL Editor → Run).
- Подключение к базе: в начале `index.html` константы `SUPABASE_URL` и `SUPABASE_ANON_KEY`.
- Вход для команды: логин и пароль создаются в Supabase → Authentication → Users.
